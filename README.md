# Inverted Search in C

A C-based application that indexes words from multiple text files so that searches can locate matching words efficiently.

## How It Works
Instead of scanning every file from scratch for each query, the program builds an index that associates words with the files in which they occur.

## Key Concepts
- Linked data structures and indexing
- File handling and string processing
- Tokenization and search logic
- Modular C programming
